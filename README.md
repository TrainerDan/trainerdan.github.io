# trainerdan.github.io

Personal blog, built with [Jekyll](https://jekyllrb.com/) and hosted on GitHub Pages.

## Local development

```sh
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000`.

## New posts

Add a file to `_posts/` named `YYYY-MM-DD-title.md` with front matter:

```yaml
---
layout: post
title: "Post title"
date: YYYY-MM-DD 00:00:00 -0000
---
```
